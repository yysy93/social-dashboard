# 소셜링 인기페이지 대시보드

구글 시트 데이터를 실시간으로 읽어 보여 주는 정적 웹 대시보드입니다. (HTML · CSS · JavaScript, GitHub Pages 배포)

```
dashboard/
├─ index.html        화면 구조
├─ css/style.css     디자인 (반응형 · 다크모드)
├─ js/config.js      ★ 설정 (시트 ID, 탭 이름/gid) — 이 파일만 고치면 됩니다
├─ js/parser.js      CSV 파싱 · 집계 · 검증
├─ js/app.js         데이터 불러오기 · 화면 그리기
└─ tests/verify.js   (선택) 내려받은 CSV로 계산 검증: node tests/verify.js ...
```

---

## 1단계. 구글 시트 준비 (5분)

### 1-1. 공유 설정 확인
시트 오른쪽 위 **공유** → 일반 액세스를 **"링크가 있는 모든 사용자 · 뷰어"** 로 설정합니다.
(대시보드가 로그인 없이 CSV를 읽으려면 필요합니다.)

### 1-2. 탭 번호(gid) 적어 두기 — 권장
탭 이름이 조금만 달라도 다른 탭을 읽을 수 있어서, **gid로 지정하는 것이 가장 정확**합니다.

1. 시트 아래쪽에서 **킼킼킼 콘텐츠 탭**을 클릭합니다.
2. 브라우저 주소창 끝을 봅니다: `...edit#gid=123456789`
3. `#gid=` 뒤의 숫자를 적어 둡니다.
4. 아래 6개 탭 모두 반복합니다.

| 탭 | config.js 위치 |
|---|---|
| 킼킼킼 콘텐츠 탭 | `channels[0].content.gid` |
| 킼킼킼_광고 / 협찬 문의 현황 | `channels[0].ads.gid` |
| 굽굽매거진 콘텐츠 탭 | `channels[1].content.gid` |
| 굽굽_광고 / 협찬 문의 현황 | `channels[1].ads.gid` |
| 팔로워 총괄표 2026 | `followers.gid` |
| 월별 매출표 2026 | `revenue.gid` |

### 1-3. `js/config.js` 수정
메모장(또는 GitHub 웹 편집기)으로 열어 `gid: ""` 따옴표 안에 숫자를 넣습니다.

```js
content: { sheet: "킼킼킼", gid: "123456789", expect: ["킼킼킼"] },
```

> gid를 비워 두면 `sheet:`의 **탭 이름**으로 찾습니다. 이때는 탭 이름을 띄어쓰기까지 똑같이 적어야 합니다.
> 잘못된 탭을 읽으면 `expect` 검사에 걸려 **오류 안내가 뜨고 데이터는 표시되지 않습니다** (엉뚱한 숫자가 나오지 않음).

## 2단계. GitHub 저장소 만들기

1. [github.com](https://github.com) 에 로그인합니다. (계정이 없으면 **Sign up**)
2. 오른쪽 위 **＋** → **New repository**
3. 입력:
   - **Repository name**: `social-dashboard` (원하는 이름, 영문 권장)
   - **Public** 선택 (무료 계정은 Public이어야 Pages 사용 가능)
   - **Add a README file** 체크 해제 (이미 있음)
4. **Create repository** 클릭

## 3단계. 파일 업로드

1. 방금 만든 저장소 화면에서 **uploading an existing file** 링크(또는 **Add file → Upload files**)를 클릭합니다.
2. 압축을 푼 `dashboard` 폴더 **안의 내용물 전체**(`index.html`, `css`, `js`, `tests`, `README.md`)를 선택해 끌어다 놓습니다.
   - ⚠️ `dashboard` 폴더 자체가 아니라 **안의 파일·폴더들**을 올려야 `index.html`이 맨 위에 위치합니다.
   - 폴더째 끌어다 놓으면 `css/`, `js/` 구조가 그대로 유지됩니다.
3. 아래 **Commit changes** 클릭
4. 저장소 첫 화면에 `index.html`, `css`, `js`가 바로 보이면 성공입니다.

## 4단계. GitHub Pages 켜기

1. 저장소 상단 **Settings** → 왼쪽 메뉴 **Pages**
2. **Build and deployment**
   - Source: **Deploy from a branch**
   - Branch: **main** / 폴더: **/(root)** → **Save**
3. 1~3분 기다린 뒤 새로고침하면 위쪽에 주소가 뜹니다:
   `https://<내아이디>.github.io/social-dashboard/`
4. 주소를 클릭하면 대시보드가 열립니다. 🎉

> 진행 상황은 저장소 **Actions** 탭에서 볼 수 있습니다 (초록색 체크 = 배포 완료).

## 5단계. 접속 후 CORS · 데이터 확인

1. 대시보드를 열고 제목 아래 상태가 **"● 최신 데이터 · … 업데이트"**(초록 점)인지 확인합니다.
2. **F12** (Mac: `Cmd+Option+I`) → **Console** 탭에서
   - `[dashboard] 킼킼킼 콘텐츠 ← https://docs.google.com/...` 줄이 6개 보이면 **CORS 문제 없이** 모두 불러온 것입니다.
   - 빨간 `CORS` / `Failed to fetch` 오류가 보이면 아래 "문제 해결"을 보세요.
3. 맨 아래 **데이터 검증 결과**를 펼치면, 시트의 월 합계와 게시물별 직접 계산값 비교가 나옵니다.

## 데이터 갱신

- 페이지를 열 때, **↻ 새로고침** 버튼을 누를 때, 그리고 열어 둔 상태에서 **5분마다** 시트에서 최신 CSV를 다시 읽습니다.
- 구글 쪽 캐시 때문에 시트 수정 후 반영까지 **1~5분** 걸릴 수 있습니다.
- 코드나 GitHub를 다시 건드릴 필요 없이 **시트만 수정**하면 됩니다.

## 시트에서 고치면 좋은 것

| 항목 | 내용 |
|---|---|
| 월 합계 수식 | 킼킼킼 7월, 굽굽 7·8월 '전체' 행 수식이 월말 게시물을 빠뜨리고 있습니다. 대시보드는 게시물을 직접 더하므로 영향 없지만, 시트 자체 값이 틀립니다. |
| 콘텐츠 링크 | URL 칸이 '바로가기' 글자 링크라 CSV에 주소가 나오지 않습니다. 주소를 **글자 그대로**(`https://www.instagram.com/p/...`) 적으면 1위 콘텐츠 '바로가기' 버튼과 TOP 5 제목에 링크가 걸립니다. |
| 월별 매출표 2026 | 금액을 입력하면 매출 카드·월별/누적 차트가 자동으로 채워지고, 시트의 '총 매출'과 월 합계가 맞는지도 표시됩니다. 숫자는 `1,200,000` / `1200000` / `120만` 모두 인식합니다. |

## 대시보드에서 일부러 제외한 것

- **23~24년 롱폼 영상 51개**: 두 콘텐츠 탭에 똑같이 복사돼 있어 제외 (`config.js`의 `fromDate`로 조정 가능)
- **광고 문의 탭의 '출연 문의(특강)' 구역**: 개인 이메일·메일 링크가 있어 공개 사이트에서 제외 (`*`로 시작하는 구역 아래는 읽지 않음)
- 시트의 **'월 전체' 합계 행**, `#REF!` 오류 셀, 제목이 비어 있는 예정 행

## 문제 해결

| 증상 | 해결 |
|---|---|
| "로그인 페이지가 왔어요" | 1-1 공유 설정을 "링크가 있는 모든 사용자"로 변경 |
| "다른 탭을 읽은 것 같아요" | 해당 탭의 gid를 config.js에 정확히 입력 |
| CORS / Failed to fetch | ① 시트 **파일 → 공유 → 웹에 게시** → 전체 문서 · CSV → 게시 ② 생성된 주소 `.../d/e/`**2PACX-…**`/pub?...` 에서 `2PACX-…` 부분을 `config.js`의 `publishedKey`에 입력 (gid 필수) |
| 화면이 안 바뀜 | GitHub 업로드 후 1~3분 대기, 브라우저에서 `Ctrl+Shift+R` (Mac `Cmd+Shift+R`) |
| 급할 때 | 오류 상자의 **CSV 올리기** 버튼으로 시트에서 내려받은 CSV를 직접 넣을 수 있습니다 (UTF-8 / 엑셀 저장본 EUC-KR 모두 지원) |

> 보안 참고: GitHub Pages 주소는 누구나 접속할 수 있고, 시트 링크 공유가 켜져 있으면 시트 전체(매출표·컨택리스트 포함)를 볼 수 있습니다. 외부 공개가 걱정되면 대시보드에 필요한 탭만 별도 시트로 옮겨 그 시트만 공유하세요.
